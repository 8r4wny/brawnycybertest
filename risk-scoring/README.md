# Risk Scoring Analysis 
This project focuses on evaluating and prioitizing security risks based on their likelihood and severity.

## Overview
The project includes a structured risk assessment table where risks are scored using a likelihood and severity scale to determine overall risk level.

## Methodology 
- Assign likelihood score
- Assign severity score
- Calculate overall risk score
- Classify risk level (e.g., Low, Medium, High, Critical)
